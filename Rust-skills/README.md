# Rust-skills

`Rust-agent-mega-01.md` is the file to give a Rust coding agent. It is one document that
covers executable specifications, architecture, testing, types, ownership, errors, async,
unsafe code, performance, web back ends, Tauri desktop apps and quality gates.

The 56 files under `sources/` are what it was built from. Each was read and its
guidance folded into the mega file, so an agent does not need to open them.

| Folder | Files | What it holds |
|---|---|---|
| `sources/idiomatic-references/` | 31 | Rust and Tauri references: the July 2026 set, the seed, and the April and June 2026 archives |
| `sources/skills/` | 16 | Archived Codex and Claude skills for Rust and Tauri, by month |
| `sources/methodology/` | 2 | The Rust and Tauri executable-specification method |
| `sources/other-rust-content/` | 7 | Pattern files and notes that are not named after Rust but are about it |

The sources were found by searching every branch of this repository by content. Files that
held nothing a coding agent can act on (data indexes, repository lists, progress logs, project
ideas, older copies of a kept file) were removed from this folder. The originals elsewhere in
the repository are unchanged.
