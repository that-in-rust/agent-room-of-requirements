## Codex Skill Status

The active Codex skill collection is managed outside this repository under
`~/.codex/skills`. Its dated repository snapshots live in
[`archive/monthly-agent-snapshots/`](../../archive/monthly-agent-snapshots/).

Create `codex/` here only when an owner selects the exact current skills to
mirror, maintain, and validate in this repository. A blind copy would create a
second, easily stale source of truth.
